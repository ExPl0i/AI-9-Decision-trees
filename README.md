# Деревья решений

Занятие курса «Искусственный интеллект» для 9 класса. Ученики разбираются, как дерево выбирает вопросы, и пишут алгоритм CART с нуля.

## Содержимое

| Файл | Описание |
|---|---|
| `Деревья_решений.pptx` | Презентация к занятию (21 слайд) |
| `ПР1-Дерево решений.ipynb` | Практическая работа (6 заданий + задания повышенной сложности) |

## Теория (презентация)

1. **Как устроено дерево** – строение, путь от корня до листа, геометрия разбиений.
2. **Как дерево учится** – чистые группы, критерий Джини и энтропия, оценка вопроса, перебор порогов, алгоритм CART, критерии остановки, глубина и переобучение.
3. **Пишем дерево на Python** – структура данных, план практики, сильные и слабые стороны.

## Практическая работа

1. Мера беспорядка: критерий Джини.
2. Качество вопроса: разбиение и прирост информации.
3. Поиск лучшего вопроса по всем признакам и порогам.
4. Построение дерева целиком (вложенные словари).
5. Дерево на датасете Wine и сверка с `DecisionTreeClassifier`.
6. Глубина и переобучение: точность в зависимости от `max_depth`.

Задания повышенной сложности: критерий энтропии, параметр `min_samples_leaf`, важность признаков, ускорение `best_split`.

**Правило работы:** внутри функций дерева – только списки, словари, циклы и `math`. `sklearn` нужен только для сверки в задании Д5.

## Требования

Python 3.8+, `numpy`, `pandas`, `scikit-learn`, `matplotlib`.
